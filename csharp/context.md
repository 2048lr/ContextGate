# ContextGate C# 代理服务器

这是一个简单的测试上下文文件。

## 项目结构

- ContextGate.Core - 核心业务逻辑
- ContextGate.Proxy - ASP.NET Core 代理服务器
- ContextGate.Desktop - Avalonia 桌面应用
- ContextGate.CLI - 命令行工具
- ContextGate.Tests - 单元测试

## 功能特性

1. AI 请求代理与转发
2. LRU 缓存机制
3. 上下文签名与变更检测
4. Token 使用监控
5. 多提供商支持（OpenAI、DeepSeek、智谱）
